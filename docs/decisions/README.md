# Decisions

This folder is the log of important decisions: the context, the chosen option and the consequences of each, numbered in
the order they were made. Work goes task, plan, PR, decisions log, and [the rules](AGENTS.md) say when a PR adds a
record. Use [the template](TEMPLATE.md).

Records are history, and some have been superseded: consult current architecture and runbooks for today's behavior. What
changed day to day is in git history.
