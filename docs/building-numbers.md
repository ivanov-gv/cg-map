# Building house numbers

House-number labels appear inside existing building footprints when the bottom-left metric scale reaches 100 m, and remain enabled at closer scales. The cutoff uses the same ground distance across 100 screen pixels as the scale control, following latitude and camera changes. Labels use local fonts and normal collision avoidance, so closely spaced numbers may be suppressed until zooming in further. Clicking anywhere on a numbered building offers its address and From/To actions, even when its number is hidden by label collisions or the scale cutoff. Labels are included in the saved offline map.

The legacy geometry export dropped address tags. data/tools/build-building-labels.py recovers them from the exact reviewed Geofabrik PBF (SHA-256 checked before processing). It matches existing rounded footprint rings to OSM building ways, recovers real way IDs, and prefers a direct building addr:housenumber. If absent, it uses address nodes only when uniquely associated by original node membership or polygon containment. It does not choose the nearest building or interpolate house numbers. Locally used bb/bez broja placeholders mean no number and are excluded. Buildings with no recorded number remain blank. Invalid or ambiguous geometry/associations are skipped.

The label anchor is an interior point with high edge clearance. Original footprint geometry and the PMTiles basemap stay unchanged; the separately published GeoJSON label layer adds the recovered metadata without rebuilding geography. Selection joins the polygon’s generated vector-tile ID to the revision-bound footprintIndex in the address snapshot. Archive integration tests verify all numbered footprints have the correct ID and location before release; these indices are not stable identities across source revisions. Polygon hits take precedence over label hit boxes. Node-derived addresses retain their original source IDs. The provenance file records source PBF hash, footprint hash, record counts, method and label file hash. The root validator checks every label lies inside its referenced polygon and outside holes. Address metadata is OSM/ODbL data, not inferred or Google-derived.

To reproduce, install data/tools/requirements.txt, then run `python data/tools/build-building-labels.py /path/to/reviewed/montenegro.osm.pbf`. A different source PBF requires explicit provenance review and an updated hash gate. Run make check and browser acceptance. Fresh full extraction also now retains OSM building identity, name, and address tags rather than discarding them. This feature does not promise unrecorded numbers or building coverage outside the existing detailed area.
