# Management

This folder describes how the project manages work: from ideas in the Wiki through Epics, Features, Tasks and Bugs to
review and release.

- [Management workflow](management.md): the milestone-driven workflow, issue hierarchy rules, and the role of the Wiki.

The [wiki Management page](https://github.com/ivanov-gv/cg-map/wiki/Management) is the authoritative source. This
repository copy exists so agents working in the repository follow the workflow; when the two disagree, the wiki wins.
