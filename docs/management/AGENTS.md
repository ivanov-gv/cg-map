# Management

- The [management workflow](management.md) describes how work flows from the Wiki through Epics, Features, Tasks and
  Bugs to review and release.
- The [wiki Management page](https://github.com/ivanov-gv/cg-map/wiki/Management) is the authoritative source; this
  repository copy exists so agents working in the repository follow the workflow. When the two disagree, the wiki wins.
- Do not invent new process. Update the wiki first, then sync the repository copy.
- The wiki is human-written: read it freely, but never edit or push to it. Propose changes as comments on the relevant
  issue so a human can apply them.
