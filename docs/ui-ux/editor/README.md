# Editor UI/UX

This folder holds interface proposals for the internal source editor in `apps/editor`. The editor is a maintainer tool,
outside the public Discover → Understand → Plan → Travel journey, so its proposals do not cite public `US-##` stories.

- [Map-first editor](map-first-proposal.md): a full-screen map with optional panels on desktop and mobile, and applied
  edits shown on the map at once. Proposed, ready for review; not implemented.

What the editor does today is described in [its README](../../../apps/editor/README.md), and what each source file
allows in [the shared layer rules](../../../packages/contracts/editor-layers.json).
