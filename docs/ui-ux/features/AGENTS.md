# UI feature documents

- Each feature guide must name the `US-##` stories it serves and state how its user-visible behavior advances those
  outcomes.
- Describe current behavior separately from approved targets or proposed changes; identify implementation gaps
  explicitly.
- Keep source-level detail in the owning component and cross-component boundaries in `../../system-architecture/`.
- Update the feature map in this folder's `README.md` when adding, moving, or changing feature coverage.
