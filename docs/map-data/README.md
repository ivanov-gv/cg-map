# Map data

This folder covers the map's dataset and imagery terms, the building-number label dataset, and the hard-coded town
coverage audit. Data acquisition, validation, and packaging procedures are in the [data runbook](../runbooks/data.md);
source ownership is documented in the [`data/` component guide](../../data/README.md).

- [Data licensing](data-license.md) records attribution and redistribution terms.
- [Building numbers](building-numbers.md) covers label source recovery, placement, and refresh.
- [Hard-coded towns](hard-coded-towns.md) compares existing town labels and positions with the OSM settlement source.
