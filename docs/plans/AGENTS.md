# Task plans

- Use `TEMPLATE.md` for multi-session work and keep scope, tests, and risks concrete.
- A plan stays until its work is finished. Delete it only then, in the PR that finishes it; git history keeps it.
- An unfinished plan continues in a new PR. Update its status and remaining work in each PR that advances it.
- Move anything still true into the owning documentation before deleting a plan, and its decisions into
  [the decisions log](../decisions/AGENTS.md).
- Do not treat a plan as current implementation documentation.
- Link current behavior to its authoritative component or documentation page.
