# Plans

This folder holds plans for work in progress. Use the [plan template](TEMPLATE.md) for a new multi-session change and
update the plan when its scope or acceptance criteria change. A plan stays until its work is finished, however many PRs
that takes, and the PR that finishes it deletes it. Git history keeps deleted plans.

- [Internal layer editor](internal-layer-editor.md): source inventory, shared map, editing slices and HTML draft. Slices
  1 to 6 and the offline install are merged, with listed gaps.
- [Faster browser tests](faster-browser-tests.md): CI jobs are split to fit their limit; the remaining steps towards a
  5-minute full suite locally.

- [Apps readability review](apps-readability-review.md): review findings, refactoring and remaining verification.
