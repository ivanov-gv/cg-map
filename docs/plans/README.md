# Plans

This folder holds plans for work in progress. Use the [plan template](TEMPLATE.md) for a new multi-session change and
update the plan when its scope or acceptance criteria change. Each plan goes to main in one PR, and that PR deletes it.
Git history keeps deleted plans.

- [Internal layer editor](internal-layer-editor.md): source inventory, shared map, editing slices and HTML draft. Slices
  1 to 6 implemented, with listed gaps.
- [Faster browser tests](faster-browser-tests.md): the remaining steps towards a 5-minute full suite.
- [Apps readability review](apps-readability-review.md): review findings, refactoring, verification and the PR #20 merge
  dependency.
