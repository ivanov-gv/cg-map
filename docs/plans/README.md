# Plans

This folder holds plans for work in progress. Use the [plan template](TEMPLATE.md) for a new multi-session change and
update the plan when its scope or acceptance criteria change. Each plan goes to main in one PR, and that PR deletes it.
Git history keeps deleted plans.

- [Monorepo CI and separate CD](change-aware-ci.md): one pipeline per folder, diff-aware browser areas, a required
  `CI gate`, and CD split from CI; in progress.
